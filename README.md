# 🕌 تفاسير الشيعة — Tafasir Al Shia

تطبيق **"تفاسير الشيعة"** هو تطبيق شامل لعرض مجموعة من تفاسير القرآن الكريم المعتمدة على روايات **أهل البيت عليهم السلام**، مع إمكانية استعراض أكثر من تفسير للآية الواحدة ومقارنتها بسهولة.

تمت إعادة بناء التطبيق في **الإصدار 2** باستخدام **Tauri 2** مع تحسينات كبيرة في الأداء، استهلاك الذاكرة، إدارة البيانات، البحث، المحفوظات، ودعم أنظمة تشغيل متعددة.

يعمل التطبيق بالكامل محليًا بعد تحميله، ولا يحتاج إلى اتصال بالإنترنت لعرض القرآن أو التفاسير.

---

## 🚀 الإصدار 2

أُعيد تصميم التطبيق وبنيته الداخلية بشكل كبير في الإصدار الثاني، ومن أبرز التحسينات:

- تقليل استهلاك الذاكرة وتحسين سرعة بدء التطبيق والتنقل بين السور.
- إعادة بناء التطبيق باستخدام **Tauri 2**.
- دعم Windows وmacOS وLinux.
- إضافة نظام **المحفوظات / العلامات المرجعية**.
- حفظ المحفوظات محليًا على الجهاز.
- إمكانية **تصدير واستيراد المحفوظات**.
- تحسين البحث في السور والآيات.
- تحسين التنقل بين السور والآيات.
- تحسين معالجة الأخطاء وحالات عدم توفر البيانات أو التفسير.
- إعادة تنظيم الكود وبنية التطبيق لتسهيل التطوير والصيانة مستقبلًا.
- الاحتفاظ بواجهة خفيفة مبنية باستخدام HTML وCSS وJavaScript بدون إطار JavaScript ثقيل.

## ⬇️ التحميل (Download)

لتحميل أحدث إصدار:

1. اذهب إلى قسم **[Releases](../../releases)** في هذا المستودع.
2. اختر أحدث إصدار.
3. حمّل الملف المناسب لنظام التشغيل لديك:

| النظام | الملف |
|---|---|
| 🪟 Windows | `Tafasir-Al-Shia-Windows.exe` |
| 🍎 macOS | `Tafasir-Al-Shia-macOS-Universal.zip` |
| 🐧 Linux | `Tafasir-Al-Shia-Linux.AppImage` |

### Windows

حمّل:

`Tafasir-Al-Shia-Windows.exe`

ثم شغّله مباشرة.

**لا يحتاج إلى تثبيت.**

### macOS

حمّل:

`Tafasir-Al-Shia-macOS-Universal.zip`

ثم فك الضغط وشغّل تطبيق `.app`.

نسخة macOS هي **Universal** وتدعم:

- Apple Silicon
- Intel Macs

### Linux

حمّل:

`Tafasir-Al-Shia-Linux.AppImage`

ثم امنحه صلاحية التشغيل إذا لزم الأمر:

```bash
chmod +x Tafasir-Al-Shia-Linux.AppImage
